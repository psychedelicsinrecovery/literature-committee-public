# Member materials

Edit canonical Markdown in `source/`, install the dependencies in `requirements.txt`, then run `python3 build.py` and `python3 build-suite.py`. Review the generated PDFs and include them in the same pull request. The mirror publishes committed PDFs; it does not rebuild them.

The suite includes the newly authored Sponsorship & Co-Travel handout. The historical Sponsorship PDF is preserved unchanged under its original CC BY-NC-ND 4.0 license and is not included in the combined edition. Staying Connected incorporates the previously separate Zoom, Discord and parking-lot topics; the standalone Markdown drafts are retained for source history and are not rendered by the builder.
