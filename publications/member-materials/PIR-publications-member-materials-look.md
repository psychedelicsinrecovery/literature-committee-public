# PIR® publications: member materials look

Use Markdown as the editable source and the PDF as a generated, printable edition. Members with access can use GitHub's Edit button to suggest a change by pull request. The PDF should never be the only editable copy.

## Visual defaults

Use the official aurora banner and diamond-and-eye mark, EB Garamond with real bold faces, dark blue titles, purple headings, blue active links and a low-opacity logo watermark. Use visible PIR® and Psychedelics In Recovery™ marks in current editions, without changing URLs, file names or immutable historical artifacts. Put the year and rights line in the footer and preserve any separate license. Use a compact, readable tag legend. Draft notices should be blockquotes.

## Publication order

1. Edit or propose the Markdown change in GitHub.
2. Review wording and original sources; review the generated PDF for pagination, links and legibility.
3. Merge source and PDF together in the private source repository, and verify the public mirror serves the correct bytes.
4. Only then point WordPress to the mirrored edition. Keep prior editions and their source notes under publications.

Do not publish the modified Sponsorship proof without applicable permission. The unmodified CC BY-NC-ND 4.0 source remains the public edition. Keep member materials separate from the future PIR-publications-public-deliverables-look.md.
